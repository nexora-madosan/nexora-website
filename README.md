# NEXORA — Build • Learn • Evolve.

Static website (HTML, CSS, vanilla JS). No build step, no backend.

## Deploy on GitHub Pages
1. Push all files to a repository (keep `index.html` at the root).
2. Settings → Pages → Deploy from branch → `main` / root.
3. All paths are relative, so it works under `https://user.github.io/repo/`.

## Contact links
Email, LinkedIn and GitHub are set in the Contact section and the footer of `index.html`. External links open in a new tab with `rel="noopener noreferrer"`.

## Add projects later
The Projects section currently shows a "Projects Coming Soon" panel. When you have real projects, replace the `<div class="soon">` block in `index.html` with your project cards.

## Files
`index.html` · `style.css` · `script.js` · `assets/favicon.svg`
Fonts (Space Grotesk, Inter) load from Google Fonts; the site falls back to system fonts offline.
